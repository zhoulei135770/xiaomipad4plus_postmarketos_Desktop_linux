## 77. 结论：rev4 配置下信号增强，但仍不随手指变化（2026-10-28 09:20）

### 本轮又解决了两件事
1. **确认芯片是 revision 4**（寄存器宽度 2/3/9 匹配 rev4，4 字节会丢首字节排除 rev5）
2. **`IMG_CAPT_SIZE` 行数决定真实数据量**：
   ```
   0xB0000800 → 8 行真实/64      （厂商值，只够匹配用）
   0xB0001000 → 16 行真实/64
   0xB0002000 → 32 行真实/64
   0xB0004000 → 64 行真实/64     ← 完整帧
   ```
   之前只要 8 行，其余 56 行是 `0xBD/0xC0` 交替填充 → 这是"平坦"的直接原因之一

### rev-4 配置的效果
| | rev-3 | rev-4 |
|---|---|---|
| mean | 99.0 | **195.3** |
| sd | 0.14 | **3.21** |
| 灰阶 | 3 | **35** |

### 但决定性实验表明：**输出不随手指变化**
1. 拍"暗帧"（无手指）对比"手指帧"：
   - 两帧 mean **完全相同**（195.3 / 195.3）
   - 差值只有 sd 2.56，且差值图是**行级漂移**，不是脊线
2. 二维自相关显示 **dx=8 的强周期（0.705）** —— 是 8 通道 ADC 的固定图案，
   试了 7 种去交织公式，最低只能降到 0.403，没有一种能消除
3. 说明了布局/去交织都解决不了根本问题

### 结论
**模拟前端没有感知到手指的电容变化。**
配置层面已经做到与厂商 rev-4 完全一致，剩下只能是：
- 硬件（传感层与 AFE 之间）
- 或厂商 TA 里另有一段**激励/标定**流程（不在 `FUN_0006fedc` 里）
- 或该 hwid 需要厂商标定数据
